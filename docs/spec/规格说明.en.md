## Main Functions
The platform supports efficient database operations and effective data maintenance and display. It contains relevant simulation/validation data and establishes a rational data handling model. Data interaction and functional processing are complete, enabling reliable data interaction management.

## Technical Features
Cloud-computing software. Powerful functions and robust network security mechanisms support efficient database operations, with effective data maintenance and display.

## V2.0 Updates
- History and alarm records export to CSV / Excel / JSON.
- History adds dust concentration, feed liquid pressure, atomizer oil pressure, fan/atomizer frequency.
- Parameter page completed with feed pump parameters, alarm thresholds, and electric heater enable.
- Temperature/pressure/frequency thresholds added to alarm logic.

## Parameter List (Summary)
- Frequency parameters: atomizer frequency, blower frequency, induced draft fan frequency.
- Feed pump parameters: feed frequency, manual frequency, auto upper/lower limits, spray ash / discharge interval.
- Temperature parameters: forced spray temperature, feed pump enable inlet/outlet temperature, feed pump stop temperature, outlet temperature setpoint, emergency fan start/auto start temperature, fan stop temperature, atomizer oil temperature.
- Pressure/time/concentration: feed liquid pressure upper limit, dust concentration upper limit, atomizer vibration upper limit, dust cleaning work time, spray time for start/stop, tank weight lower limit, mixer reminder tank weight.
- Alarm thresholds: blower/induced draft fan fault frequency upper/lower limits, inlet/outlet temperature upper/lower limits, atomizer fault frequency, atomizer oil pressure upper limit, atomizer working time.
- Electric heater enable: 1#~10# heater enable switches.

## History Fields (V2.0)
Time, inlet temperature, outlet temperature, pressure differential, dust concentration, feed liquid pressure, atomizer oil pressure, blower frequency, induced draft fan frequency, atomizer frequency.
