# 装配工艺仿真与优化验证平台

面向作品集展示的本地演示项目，用于复刻机械装配工艺系统的典型流程、联锁逻辑、报警机制与数据展示方式。项目不连接真实设备，仅用于学习与展示。

## 项目概览
- 面向：机械设计制造及其自动化专业课程/项目展示
- 目标：以可视化界面与状态机演示工艺流程、联锁、参数设定、报警与历史数据
- 说明：演示用途，不用于现场实际控制

## 主要功能（演示版）
- 主界面：系统概览与状态提示
- 历史数据：按时间范围查询（模拟数据）
- 报警查看：报警列表与消音逻辑（仅消音，不解除报警）
- 操作界面：设备启停与状态灯
- 参数设定：关键工艺参数配置（带合法性约束）
- 一键开机/关机：按手册流程自动演示

## 关键流程（演示逻辑依据）
开机流程：
1. 清灰/气锤/关风机
2. 油泵/冷风机
3. 雾化器
4. 加料泵阀门/加料泵
5. 鼓风机/引风机
6. 加热
7. 喷水，满足 $t \\ge 40\\,\\text{min}$ 后切喷料

关机流程：
1. 喷水，满足 $t \\ge 40\\,\\text{min}$
2. 关加热
3. 加料泵待机/停机，关闭加料泵与阀门
4. 关雾化器（倒计时结束后）
5. 关油泵/冷风机
6. 进风温度满足 $T_{in} < 50\\,^{\\circ}\\mathrm{C}$ 后关引风机/鼓风机
7. 关清灰/气锤/关风机

## 技术方案（计划）
- 语言与框架：Python 3.13 + PyQt6 + QFluentWidgets
- 架构：状态机（流程与联锁）+ 数据模拟（历史/报警/参数）+ 本地持久化
- 数据保存：JSON 或 SQLite（用于参数与历史数据）
